Privacy Policy

Last updated: 2026-10-23

AI Longform Editor ("the app") is a private desktop tool used only by its owner to upload edited videos to the owner's own YouTube channels.

What the app accesses

With the owner's permission, the app uses the YouTube Data API to: upload videos, set thumbnails, upload captions, update titles, descriptions and publishing times, and read basic information (channel ID, video status and view counts) of the channels the signed-in account manages.

How data is stored

The OAuth refresh token is stored only on the owner's own Windows computer, in the Windows Credential Manager. Video files and captions stay on that computer until they are uploaded to YouTube. The app has no server and does not collect, sell, share or transfer any Google user data to anyone else.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: GitHub issues.
